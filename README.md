# Assignment 5 – Individual Work

This project contains Tasks 6–12, covering basic JavaScript concepts.

Task 6: Variables and Data Types
Declared variables using `let` and `const`, printed their values and data types, and demonstrated reassignment.

Task 7: Input and a Greeting
Used `prompt()` to ask for a name, `alert()` to display a greeting, and `console.log()` to print a greeting with my name and group.

Task 8: Sum and Arithmetic
Used `prompt()` and `Number()` to input and convert two numbers. Calculated the sum, difference, product, quotient, and remainder.

Task 9: Strings
Used `.length`, `.toUpperCase()`, `.toLowerCase()`, and `.slice()` to work with strings. Combined two strings into a sentence.

Task 10: Increment and Assignment Operators
Used `++`, `--`, `+=`, `-=`, `*=`, and `/=` to change a counter's value and print the results.

Task 11: Dog Age Calculation
Applied the formula `humanAge = (dogAge - 2) * 4 + 21` and tested it with dog ages 2 and 5.

Task 12: Functions
Created and called three functions: `greetUser()`, `calculateSum()`, and `calculateRectangleArea()`. Practised parameters, arguments, and return values.
